## 4. Notion 연동 시 확인 사항

### HTML 블록·embed 공통 (M4 화면 구현 규칙)
- **`position: fixed` 오버레이 금지.** iframe 높이가 내용에 맞춰 늘어나면 fixed 패널이 iframe 맨 위에 붙어 화면 밖에 뜰 수 있다. 상세는 명세대로 `#/p/{id}` 페이지 전환으로 한다. (검토 페이지의 오른쪽 패널은 로컬 검토용이라 예외)
- **`history.replaceState` 대신 `location.hash`만 쓰고 try/catch.** sandbox iframe(origin null, about:srcdoc)에서는 URL 변경 API가 SecurityError를 낼 수 있다.
- **외부 요청 0개.** 데이터·CSS·JS 전부 인라인. 웹폰트 없음 (시스템 폰트).
- DOI 링크는 `target="_blank"`. 팝업이 막히면 링크가 안 열릴 수 있어 M7 테스트 항목에 있음.
- 다크 모드: iframe은 Notion 설정이 아니라 OS 설정(`prefers-color-scheme`)을 따른다. Notion만 다크이고 OS가 라이트면 어긋난다 → 미확인, M6/M7에서 확인.
- 신규 판정은 저장된 `status`만 믿지 말고 빌드 시 `added_at`으로 다시 계산 (빌드와 수집 날짜가 다를 수 있음).

### 데이터를 Notion DB로 옮길 경우 (C안)
- 연결 키: 논문 `id`(고정됨), 교수 `id`. 매주 갱신하려면 `id → Notion 페이지 id` 매핑 파일이 필요하다.
- 교수 ↔ 논문은 Relation 속성. 공저 16편은 Relation 2개로 자연스럽게 표현된다.
- 카테고리는 다중 선택. 이름에 쉼표 불가 → 테스트로 검사함. 이름은 한글명(전 교수 간 중복 없음).
- 학술지는 쉼표 든 이름이 13개라 선택 속성이 아니라 텍스트로.
- 텍스트 속성 2,000자 제한: 현재 최대 249자라 문제 없음.
- API 평균 초당 3회 제한: 첫 업로드 404편 약 2~3분, 이후 주간 갱신은 피인용 수 변경분만.
